# ViralForge AI Studio

This is the upgraded static version of ViralForge.

## What works now
- Command Center
- Autopilot test scheduler
- Batch generation
- Idea Lab
- Production queue
- Script/hook package generation
- Progress pipeline
- Local analytics
- Export individual packages or the whole queue as JSON
- Local settings
- Responsive layout
- Data persistence with localStorage

## Important
The browser version does NOT pretend that a YouTube upload happened. Real YouTube publishing needs OAuth/API credentials and a secure backend. Do not put private API secrets into `index.html`.

## GitHub Pages
Replace the repository's `index.html` with this file. GitHub Pages can then serve it as a static site.

The site is intentionally usable without API keys, so you can test the whole front-end immediately.
